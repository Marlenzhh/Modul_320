# Kompetenznachweis für D1

### Lernziele:

* Ich kann eigene Klassen entwerfen und daraus Objekte instanziieren
* Die Objekte können miteinander kommunizieren, indem ihre Methoden aufgerufen werden
* Es können auch Werte an andere Objekte übergeben werden
* Ich kann Attribute so anpassen, damit sie nicht von aussen veränderbar sind
* Ich kann aufzeigen, wie der Status eines Objekts verändert werden kann, indem ich die Attribute verändere


### Ziel:

Mit Hilfe von KI und den Unterrichtsinhalten arbeiten Sie sich *selbstständig* in die beschriebenen Themenbereiche ein. Sie suchen sich weiterführende Informationen und lassen sich Details von der KI oder der Lehrperson erklären, so dass Sie sich ein umfangreiches Wissen aneignen. 

### Auftrag:

Ihr Programm soll die beschriebenen Lernziele aufzeigen. Arbeiten Sie mit KI an möglichen Implementationen, welche diese Themen abbilden.
Als Resultat zeigen Sie **zwei Implementationen** der Lehrperson.

### Mögliche Ideen für eine Lösung:

* Eine Garagen-Simulation: Fahrzeuge können zur Reparatur registriert werden. Dabei werden die Reparaturkosten aufgelistet. Der *Benutzer* kann abfragen, welche Fahrzeuge schon repariert sind und wie hoch die Kosten sind.
* Eine Bank-Simulation: hier kann der *Benutzer* zwischen Konti auswählen und z.Bsp. einen Transfer zwischen zwei Kontos machen (nebst den klassischen Funktionen wie Einzahlen und Abheben):
* Heizungssystem: in einem Haus hat es pro Raum eine Heizung, welche von einer zentralen Stelle aus reguliert werden kann. Somit kann die Temperatur pro Zimmer abgefragt und verändert werden.
* Eine eigene Idee umsetzen. Besprechen Sie das mit der Lehrperson.

### Fragen zur Besprechung:

* Zeigen Sie die Datenkapselung. Wie wird der Zugriff auf Attribute gelöst?
* Zeigen Sie auf, wie Objekte miteinander kommunizieren? Werden dabei Werte mitgegeben?
* Zeigen Sie, wie sich der Zustand eines Objekts verändert.
* Was ist der Unterschied zwischen einem primitiven und komplexen Datentyp? Zeigen Sie Beispiele in Ihrem Code.
