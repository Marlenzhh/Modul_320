# Kompetenznachweis für D2

### Lernziele:

* Ich kenne die verschiedenen HAT-Beziehungen (lose Koppelung bis starke Abhängigkeit)
* Ich kann Aggregation und Komposition im Code unterscheiden und aufzeigen.
* Ich kann aufzeigen, wie ein Aufruf an ein anderes Objekt delegiert wird.


### Ziel:

Mit Hilfe von KI und den Unterrichtsinhalten arbeiten Sie sich *selbstständig* in die beschriebenen Themenbereiche ein. Sie suchen sich weiterführende Informationen und lassen sich Details von der KI oder der Lehrperson erklären, so dass Sie sich ein umfangreiches Wissen aneignen. 

### Mögliche Ideen für eine Lösung:

* Flüge und Zeitplan: Ein Flug hat mehrere Passagiere. Wir wollen pro Flug die Liste der Passagiere ausgeben. Wir wollen auch Passagiere hinzufügen und entfernen. Alle Flüge können in einer Zeitplan Klasse aufgelistet und verwaltet werden. Wir können z.Bsp. danach suchen, wann welche Flüge starten.
* Komposition darstellen: in einem bestehenden Darstellungstool *Haus* kann eine zusätzlich Klasse *Cloud* erstellt werden. Diese erzeugt ein Objekt, das sich langsam in der Grafik bewegt. Dabei soll anschliessend eine Person zum Haus gehen. Den bestehenden Code ist [hier](https://gitlab.com/JulianKaser/javaressources/-/tree/main/code/House?ref_type=heads).
* Auktions-App: Implementieren Sie eine App, welche eine online Auktion abbildet. Dabei sollte das Design eine Kette von Objekt-Referenzen abbilden. Siehe Abbildung als Idee:
[Auction](../../x_gitres/auction.png)
* Ihre eigene Idee, welche dem Niveau 2 entspricht. Besprechen Sie Ihre Idee *zuerst* mit der Lehrperson, bevor Sie mit dem Codieren beginnen.

### Fragen zur Besprechung:

* Welche HAT-Beziehungen werden wann verwendet? Erklären Sie mögliche Szenarios.
