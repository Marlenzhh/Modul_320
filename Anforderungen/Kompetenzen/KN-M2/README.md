# Kompetenznachweis für M2

### Lernziele:

* Ich kann für einen bestimmten Use Case die Interaktion zwischen den Objekten grafisch darstellen.
* Ich kenne die wichtigsten Symbole eines UML Sequenzdiagrammes, um den Use Case darzustellen.
* Ich kenne den Unterschied zwischen einer dynamischen und statischen Darstellung.
* Ich kann ein Sequenzdiagramm mit einem passenden Tool umsetzen. PlantUML eignet sich sehr gut.


### Ziel:

Mit Hilfe von KI und den Unterrichtsinhalten arbeiten Sie sich *selbstständig* in die beschriebenen Themenbereiche ein. Sie suchen sich weiterführende Informationen und lassen sich Details von der KI oder der Lehrperson erklären, so dass Sie sich ein umfangreiches Wissen aneignen.
Für die Darstellung von Sequenzdiagrammen eignet sich PlantUML. 
Beispiele inkl. Code: https://plantuml.com/sequence-diagram


### Auftrag:

* Sie verwenden **Ihren Code** aus Niveau 2 um einen Use Case als Sequenzdiagramm zu zeichnen. Achten Sie darauf, dass Sie einen Use Case nehmen und diesen darstellen.
* Alternative Variante:
Sie arbeiten mit fremden *Code*, den Sie zuerst zum Laufen bringen. Sie stellen einen bestimmten Use Case als Sequenzdiagramm dar.

Besprechen Sie den Auftrag mit der Lehrperson, *bevor* Sie mit der Arbeit beginnen.

#### Fremder Code:
**Tech-Support App**: Wählen Sie **einen UseCase** und verfolgen Sie die entsprechenden Aufrufe im Code.
Zeichnen Sie dazu ein Sequenzdiagramm. Welche Objekte werden wann aufgerufen?
Der Code befindet sich hier: https://gitlab.com/JulianKaser/javaressources/-/tree/main/code/TechSupportApp?ref_type=heads

**Fun Fact**: dieses simple Programm ist in Anlehnung an eines der ersten KI-Systeme aus den 60er Jahren. Recherchieren Sie zu *ELIZA*, welches damals mit einem Regelwerk entwickelt wurde.


### Fragen zur Besprechung:

* Wie werden Aufrufe von einem Objekt zu einem anderen dargestellt?
* Was sind Swimlanes?
* Kann ich in einem Sequenzdiagramm sehen wie lange ein Objekt "lebt" ?
* Wie kann die Antwort (Return-Value) von einem Objekt dargestellt werden?
* Wie werden Aufrufe innerhalb desselben Objekts dargestellt?
* Wie kann ich eine *alternative Sequenz* im Diagramm zeigen?
