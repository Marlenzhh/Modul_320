# Kompetenznachweis für V1

### Lernziele:

* Ich kann eigene Klassen erstellen, welche sich von abstrakten Klassen ableiten oder Interfaces implementieren (z.Bsp. Comparable oder Iterator)
* Ich kann eigene Klassen erstellen, welche eine bestehende Collection Klasse erweitern (Stichwort *extends*)
* Ich kann eine einfache Hierarchie implementieren, indem Gemeinsamkeiten in eine Ober-Klasse zusammengefasst werden
* Ich kann aufzeigen, wie Attribute in der Superklasse ihre Werte erhalten.


### Ziel:

Mit Hilfe von **KI** und den **Unterrichtsinhalten** arbeiten Sie sich **selbstständig** in die beschriebenen Themenbereiche ein. Sie suchen sich weiterführende Informationen und lassen sich Details von der KI oder der Lehrperson erklären, so dass Sie sich ein umfangreiches Wissen aneignen. 

### Auftrag:

Ihr Programm soll die beschriebenen Lernziele aufzeigen. Arbeiten Sie mit KI an möglichen Implementationen, welche diese Themen abbilden.
Als Resultat zeigen Sie *zwei Implementationen* der Lehrperson.
Eine Implementation demonstriert eine einfache Hierarchie. Hier zeigen Sie auch, wie definierte Attribute in der Superklasse ihre Werte erhalten.
Die andere Implementation arbeitet mit bestehenden Interfaces und Collections.

### Mögliche Ideen für eine Lösung:

* Fragen Sie die KI nach möglichen Lösungen. Stellen Sie sicher, dass Sie den vorgestellten Code verstehen und der Lehrperson erklären können.


### Fragen zum Thema:

* Was ist der Unterschied zwischen einer ArrayList, einem Set und einer Map?
* Was macht das Interface Comparable<T>?
* Was macht das Interface Iterator?
* Was ist der Unterschied zwischen Comparable und Comparator? Beschreiben Sie ein mögliches Szenario.
* Was ist der Unterschied zwischen einem Vector und einer ArrayList?
* Wie werden Attribute in der Superklasse von den Subklassen gesetzt?
