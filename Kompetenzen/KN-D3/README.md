# Kompetenznachweis für D3

### Lernziele:

* Ich kann eine eigene Beschreibung für eine Applikation notieren
* Ich kann Delegation in meinem Beispiel anwenden
* Ich kann Benutzer-Eingaben validieren und bei falschem Input eine eigene Exception werfen
* Ich kann eine saubere Trennung anwenden im Code von User-Input, Logik, Service-Aufrufe


### Ziel:

Mit Hilfe von KI und den Unterrichtsinhalten arbeiten Sie sich *selbstständig* in das Thema **Delegation** ein. Sie suchen sich weiterführende Informationen und lassen sich Details von der KI oder der Lehrperson erklären. 

### Auftrag:

Sie erstellen eine Applikation die dem *Niveau 3 entspricht*. Der Code ist sauber getrennt in entsprechende Aufgaben. Die main-Methode ist nur noch dazu da, die Applikation zu starten.
User-Input und Logik ist klar getrennt. Verwenden Sie gegebenfalls eine fremde API (Weather-Data, Football results, etc.).

* Besprechen Sie Ihre Idee mit der Lehrperson.
* Erstellen Sie eine kurze Beschreiben als Markdown. Stellen Sie diese in Ihr Repository.

**Die Applikation wird als Einzelarbeit umgesetzt.**



### Fragen zur Besprechung:

* Zeigen Sie die Delegation.
* Zeigen Sie auf, wie Objekte miteinander kommunizieren? Werden dabei Werte mitgegeben?
* Zeigen Sie die Trennung von User-Input, Logik, Aufruf fremder Schnittstelle (API).
