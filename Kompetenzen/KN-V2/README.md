# Kompetenznachweis für V2

### Lernziele:

* Ich kann eine Vererbungs-Hierarchie gemäss einer Beschreibung oder einem Klassendiagramm umsetzen
* Ich weiss wie man gekapselte Attribute in einer Super-Klasse *trotzdem* in den Sub-Klassen verwenden kann
* Ich kann Methoden implementieren, welche die generellen Methoden der Super-Klasse **überschreiben**
* Ich kenne den Unterschied zwischen dem Überladen und Überschreiben von Methoden
* Ich verstehe das Konzept des Polymorphismus


### Ziel:

Mit Hilfe von KI und den Unterrichtsinhalten arbeiten Sie sich *selbstständig* in die beschriebenen Themenbereiche ein. Sie suchen sich weiterführende Informationen und lassen sich Details von der KI oder der Lehrperson erklären, so dass Sie sich ein umfangreiches Wissen aneignen. 

### Auftrag:

Ihr Programm soll die beschriebenen Lernziele aufzeigen. Arbeiten Sie mit KI an möglichen Implementationen, welche diese Themen abbilden.
Als Resultat zeigen Sie **zwei Implementationen** der Lehrperson.

### Mögliche Ideen für eine Lösung:

* Erweiterung der Garagen-Simulation: Erstellen Sie eine Hierarchie von Fahrzeugen, so dass es spezielle Klassen für Fahrzeugtypen gibt. Je nach Fahrzeug-Typ gibt es eine andere Kalkulation für die Reparatur. Der *Benutzer* kann abfragen, welche Fahrzeuge schon repariert sind und wie hoch die Kosten sind.
* Eine Fussballmannschaft: hier unterscheiden Sie zwischen den verschiedenen Spielern einer Mannschaft. Der Benutzer kann eine Fussballmannschaft erstellen und die Spieler trainieren lassen.
Achten Sie darauf, dass die Anzahl mögliche Spieler mit einem realen Team übereinstimmen.
* Kurs-Anmelde-Tool: In diesem Kurs gibt es Lehrpersonen und Studenten, sowie Assistenten. Bilden Sie eine sinnvolle Hierarchie ab. Der Benutzer kann Studenten für einen Kurs registrieren. Pro Kurs gibt es eine Lehrperson und ein Assistent. Ein Kurs hat eine mind. Anzahl Studenten und ein Maximum.
* Service-LeistungsTool: Eine Firma verwaltet verschiedene Services, die gebucht und verrechnet werden. Alle Services haben gemeinsame Eigenschaften wie eine ID, Name, BasisPreis, Datum und gebucht. Die Services unterscheiden sich jedoch in der Preisberechnung. Es gibt einen Beratungs-, Schulungs- und WartungsService. Beim Wartungsservice werden Anzahl Geräte aufgelistet. Die Verwaltungsklasse listet alle Services auf und berechnet den gesamten Umsatz.
* Ihre eigene Idee, welche dem Niveau 2 entspricht. Besprechen Sie Ihre Idee *zuerst* mit der Lehrperson, bevor Sie mit dem Codieren beginnen.


### Fragen zur Besprechung:

* Zeigen Sie auf, wie gekapselte Attribute trotzdem in den Sub-Klassen verwendet werden können.
* Was bedeutet Polymorphismus und wie zeigt sich das in Ihrem Code?
* Was ist der Unterschied zwischen dem Überladen und Überschreiben von Methoden? Zeigen Sie Beispiele in Ihrem Code.
* Was genau ist der Vorteil von der Vererbung?
