## Umsetzung eigenes Programm

Als Repetition erstellen Sie ein Programm. Sie können frei wählen, welches Thema Sie als Programm umsetzen wollen.
Wichtig ist, dass Ihr Programm folgende Aspekte abdeckt:
* Sie arbeiten mit einer Klasse.
* Sie verwenden mind. zwei Basis-Datentypen.
* Sie haben ein TUI, mit Ein- und Ausgabe.
* Ihr Ablauf verwendet mind. eine Schleife, eine Entscheidung und eine Abstraktion.
* Der Input muss nicht validiert werden. Gehen Sie davon aus, dass die Eingabe korrekt ist.
* Sie verwenden Methoden in der Klasse (nicht nur main-Methode).


Mögliche Ideen:

* Lotto-Programm
* Arbeitszeiterfassung (es werden Kunden und Projekte aufgelistet)
* Rate-Spiel

Ihre Idee muss mit der Lehrperson abgesegnet sein.
