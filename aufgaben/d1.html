D1: Klassen, Objekte und Kapselung

Niveau 1**

Klassen, Konstruktoren, Methoden, Kapselung

Lernziele

Auftrag

Ein Programm schreiben, das die Lernziele aufzeigt (Arbeit mit KI möglich). Als Resultat zwei Implementationen der Lehrperson zeigen.

Ideen für die Umsetzung

  • Garagen-Simulation: Fahrzeuge zur Reparatur registrieren, Kosten auflisten, abfragen was repariert ist
  • Bank-Simulation: Konti wählen, einzahlen, abheben, Transfer zwischen zwei Konti
  • Heizungssystem: pro Raum eine Heizung, zentral regulierbar
  • Eigene Idee, mit der Lehrperson besprechen

Beispiel: Bank mit Kapselung

classDiagram
direction LR
class Konto {
  -String kontonummer
  -double saldo
  +einzahlen(betrag)
  +abheben(betrag)
  +getSaldo() double
}
class Bank {
  -List~Konto~ konten
  +transfer(von, nach, betrag)
  +findeKonto(nummer) Konto
}
Bank "1" o-- "0..*" Konto

Das Attribut saldo ist private. Verändert wird es nur über einzahlen() und abheben(). Das ist Datenkapselung.

Fragen zur Besprechung

  • Datenkapselung zeigen: Wie wird der Zugriff auf Attribute gelöst?
  • Wie kommunizieren Objekte miteinander? Werden Werte mitgegeben?
  • Wie verändert sich der Zustand eines Objekts?
  • Unterschied zwischen primitivem und komplexem Datentyp, Beispiele im Code
