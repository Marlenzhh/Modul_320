D3: Delegation und eigene Exceptions

Niveau 3Einzelarbeit***

Delegation, eigene Exceptions

Lernziele

Auftrag

Eine Applikation auf Niveau 3 bauen. Die main-Methode startet nur die Applikation. User-Input und Logik sind klar getrennt. Wenn es passt, eine fremde API verwenden (Wetterdaten, Fussballresultate usw.).

  • Idee mit der Lehrperson besprechen
  • Kurze Beschreibung als Markdown ins Repo stellen

Zielarchitektur

flowchart LR
M["main() startet nur die App"] --> UI["Benutzerschnittstelle (Menü, Eingabe)"]
UI -->|validierte Eingabe| L["Logik (Service-Klasse)"]
L -->|delegiert| API["API-Client (fremde Schnittstelle)"]
L -.->|wirft bei falschem Input| E["Eigene Exception"]
E -.-> UI

Jede Schicht kennt nur die nächste. Die Logik delegiert den Aufruf der fremden Schnittstelle an einen eigenen Client.

Fragen zur Besprechung

  • Delegation zeigen
  • Wie kommunizieren Objekte miteinander? Werden Werte mitgegeben?
  • Trennung von User-Input, Logik und Aufruf der fremden Schnittstelle zeigen
