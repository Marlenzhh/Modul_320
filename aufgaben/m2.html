M2: Sequenzdiagramm zu einem Use Case

Niveau 2VisuellVorher besprechen**

Delegation als Sequenzdiagramm

Lernziele

Auftrag

Eigenen Code aus Niveau 2 oder fremden Code verwenden und einen Use Case als Sequenzdiagramm zeichnen. Den Auftrag vorher mit der Lehrperson besprechen. Als fremder Code steht die Tech-Support App zur Verfügung.

Fun Fact: Die App ist an ELIZA angelehnt, eines der ersten KI-Systeme aus den 60er Jahren.

Beispiel: Tech-Support App, Frage stellen und beenden

Basis ist der Code aus TechSupportApp (Starter, SupportSystem, InputReader, Responder). Das Innenleben von Responder ist nicht modelliert.

sequenceDiagram
autonumber
actor U as Benutzer
participant S as Starter
participant SS as SupportSystem
participant IR as InputReader
participant R as Responder
S->>SS: new SupportSystem()
SS->>IR: new InputReader()
SS->>R: new Responder()
S->>SS: start()
SS->>SS: printWelcome()
loop solange nicht "exit" eingegeben wurde
  SS->>IR: getInput()
  IR->>U: Prompt "> " ausgeben
  U-->>IR: Text eingeben
  IR-->>SS: input
  alt input beginnt mit "exit"
    SS->>SS: finished = true
  else sonstige Eingabe
    SS->>R: generateResponse(input)
    R-->>SS: response
    SS->>U: println(response)
  end
end
SS->>SS: printGoodbye()
