V1: Einfache Vererbung und Interfaces

Niveau 1Aufträge auf Papier**

Einfache Vererbung, Interfaces aus Bibliotheken

Lernziele

Auftrag

Laut Kompetenzraster sind die Aufträge von V1 auf Papier. Im Repo gibt es dazu keinen Text, den Zettel gibt die Lehrperson aus.

Zusätzlich gilt die digitale Aufgabe: zwei Implementationen der Lehrperson zeigen.

  • Eine Implementation mit einfacher Hierarchie, inklusive Wertevergabe der Attribute in der Superklasse
  • Eine Implementation mit bestehenden Interfaces und Collections

Beispiel 1: einfache Hierarchie

classDiagram
class Tier {
  -String name
  -int alter
  +Tier(name, alter)
  +getName() String
}
class Hund {
  +Hund(name, alter)
  +bellen()
}
class Katze {
  +Katze(name, alter)
  +miauen()
}
Tier <|-- Hund
Tier <|-- Katze

Der Konstruktor der Subklasse ruft mit super(name, alter) den Konstruktor der Superklasse auf. So erhalten die Attribute ihre Werte.
