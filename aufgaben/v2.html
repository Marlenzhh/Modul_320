V2: Hierarchie, Polymorphismus, Überschreiben

Niveau 2**

Vererbungshierarchie, Polymorphismus, Überladen/Überschreiben

Lernziele

Auftrag

Ein Programm schreiben, das die Lernziele aufzeigt (Arbeit mit KI möglich). Als Resultat zwei Implementationen der Lehrperson zeigen.

Ideen für die Umsetzung

  • Garage erweitern: Hierarchie von Fahrzeugtypen mit unterschiedlicher Reparaturkalkulation
  • Fussballmannschaft: verschiedene Spielertypen, Anzahl wie in einem realen Team
  • Kurs-Anmelde-Tool: Lehrperson, Studenten, Assistenten. Pro Kurs eine Lehrperson und ein Assistent, Minimum und Maximum Studenten.
  • Service-Leistungstool: Beratungs-, Schulungs- und WartungsService mit gemeinsamen Eigenschaften (ID, Name, BasisPreis, Datum, gebucht) und eigener Preisberechnung
  • Eigene Idee auf Niveau 2

Beispiel: Fahrzeuge und Polymorphismus

classDiagram
class Fahrzeug {
  -String kennzeichen
  #double basisPreis
  +berechneReparatur() double
}
class Auto {
  +berechneReparatur() double
}
class Lastwagen {
  +berechneReparatur() double
}
class Motorrad {
  +berechneReparatur() double
}
Fahrzeug <|-- Auto
Fahrzeug <|-- Lastwagen
Fahrzeug <|-- Motorrad
List<Fahrzeug> garage = List.of(new Auto(), new Lastwagen(), new Motorrad());
for (Fahrzeug f : garage) {
    System.out.println(f.berechneReparatur()); // je nach Typ eine andere Berechnung
}
